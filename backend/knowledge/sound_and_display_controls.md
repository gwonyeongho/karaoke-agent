# 음향과 화면 제어 안내

이 문서는 Karaoke AI Agent 데모에서 지원하는 음정·템포·음량·공간 음향·MR·자막 기능과 허용 범위를 정리한다.

## 음정과 키 조절

음정 또는 키 값은 -6부터 6까지다. `▲ 음정` 버튼은 현재 값에서 1을 올리고 `▼ 음정` 버튼은 1을 내린다. 자연어로는 `키 올려줘`, `키 한 칸 내려줘`, `피치 2로 맞춰줘`처럼 요청할 수 있다.

허용 범위를 넘는 값을 직접 요청하면 기기 상태를 변경하지 않는다. 예를 들어 `키를 10으로 설정해줘`는 지원 범위 밖이다. 현재 값이 6인 상태에서 더 올리는 상대 명령은 최대값 6을 넘지 않도록 처리해야 한다.

## 템포와 박자 조절

템포 값은 -5부터 5까지다. `▲ 템포`와 `▼ 템포` 버튼 또는 자연어 명령을 사용한다. `템포 1 올려`, `속도를 한 단계 낮춰줘`, `박자를 0으로 맞춰줘`와 같은 표현이 가능하다. 5보다 크거나 -5보다 작은 직접 설정 요청은 적용하지 않는다.

## 마이크 음량

MIC 다이얼은 마이크 입력 음량을 0부터 100까지 조절한다. 다이얼을 드래그하면 값이 즉시 현재 기기 상태에 반영된다. 마이크 소리가 너무 작을 때는 MIC 값을 높이고 소리가 찢어지거나 지나치게 클 때는 값을 낮춘다.

마이크 음량과 브라우저의 마이크 권한은 다른 문제다. MIC 값을 높여도 브라우저에서 마이크 권한을 거부했거나 입력 장치를 찾지 못하면 음성 명령 녹음은 시작되지 않는다.

## 반주와 멜로디 음량

INST 다이얼은 반주 음량을 0부터 100까지 조절한다. MELODY 다이얼은 멜로디 음량을 0부터 100까지 조절한다. 반주 소리와 가이드 멜로디의 균형이 맞지 않을 때 두 값을 따로 조정한다.

## 에코와 리버브

ECHO 다이얼은 에코 강도를 0부터 100까지 조절한다. 공간 음향 유형은 `Room`, `Hall`, `Stage`, `None` 네 값만 지원한다. `None`은 공간 음향을 사용하지 않는 설정이다. 정의되지 않은 다른 리버브 이름은 지원하지 않는다.

## MR과 보컬 제거

`MR ON` 버튼 또는 `MR 모드 켜`, `보컬 제거해줘` 명령은 `voice_cancel`을 켠다. `MR OFF`, `MR 해제`, `보컬 살려줘`는 보컬 제거를 끈다. 화면의 MR 칩이 ON 또는 OFF 상태를 보여준다.

MR 기능은 이 데모의 상태값을 변경하는 동작이다. 실제 음원에서 보컬을 분리하거나 제거하는 오디오 처리 모델은 포함하지 않는다.

## 자막 언어

지원 자막 언어는 한국어 `KOR`, 영어 `ENG`, 일본어 `JPN`, 중국어 `CHN`이다. 화면 버튼에는 한국어와 영어가 제공되며 나머지 언어는 자연어 명령으로 요청할 수 있다. 지원 목록에 없는 언어 요청은 기기 상태를 변경하지 않는다.

## 자주 묻는 질문

### 음정을 최대로 얼마나 올릴 수 있나요?

최대값은 6이고 최소값은 -6이다.

### 템포와 멜로디 음량은 같은 기능인가요?

아니다. 템포는 재생 속도 또는 박자 조절값이며 -5부터 5까지다. 멜로디 음량은 가이드 멜로디 크기이며 0부터 100까지다.

### 에코를 완전히 끌 수 있나요?

ECHO 값을 0으로 설정한다. 공간 음향도 사용하지 않으려면 리버브 유형을 `None`으로 설정한다.
