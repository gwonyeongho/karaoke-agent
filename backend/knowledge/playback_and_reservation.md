# 재생과 예약 사용 안내

이 문서는 Karaoke AI Agent 데모의 곡 번호 입력과 재생 대기열 기능을 설명한다. 실제 상용 노래방 기기의 공식 설명서가 아니라 이 프로젝트에서 구현한 동작을 기준으로 한다.

## 곡 번호 직접 재생

재생하려는 곡 번호를 오른쪽 숫자패드 또는 곡 번호 입력창에 입력한 뒤 `시작` 버튼을 누른다. 자연어 명령창에서는 `재생 시작 1234`처럼 말하거나 입력할 수 있다. 정상 처리되면 `played_song`에 곡 번호가 저장되고 화면 상태가 `PLAYING`으로 바뀐다.

곡 번호 없이 `시작` 버튼을 누르면 예약 목록의 첫 번째 곡을 꺼내 재생한다. 예약 목록이 비어 있으면 실행할 곡이 없으므로 상태가 바뀌지 않을 수 있다.

## 일반 예약

곡 번호를 입력하고 `예약` 버튼을 누르면 해당 번호가 예약 목록의 마지막에 추가된다. 자연어로는 `1234번 예약해줘` 또는 `예약 1234`라고 요청할 수 있다. 화면 중앙의 `[예약]` 항목에서 현재 예약 순서를 확인한다.

같은 번호를 다시 예약하는 동작은 현재 별도의 중복 차단 규칙이 없다. 의도하지 않은 중복 예약은 예약 취소 기능으로 제거한다.

## 우선예약

곡 번호를 입력하고 `우선예약` 버튼을 누르면 해당 곡이 예약 목록의 맨 앞에 추가된다. 자연어로는 `1234번 우선예약해줘` 또는 `1234번 새치기 예약`처럼 요청할 수 있다. 다음에 예약곡 시작을 실행하면 목록 맨 앞의 곡부터 재생된다.

## 예약 취소

취소할 곡 번호를 입력하고 `예약취소` 버튼을 누른다. 자연어로는 `예약 취소 1234`라고 요청한다. 해당 번호가 예약 목록에 없으면 상태가 변경되지 않는다.

현재 화면의 `우선취소` 버튼도 곡 번호를 입력한 뒤 사용한다. 프로젝트 상태 모델에는 별도의 우선예약 목록이 없고 우선예약 역시 일반 예약 목록 앞쪽에 저장되므로 구현 시 동일한 예약 목록을 기준으로 취소 여부를 확인해야 한다.

## 재생 정지와 취소 버튼

오른쪽 숫자패드의 빨간색 `취소` 버튼은 현재 구현에서 `정지` 명령을 전송한다. 정지 명령이 적용되면 재생 중인 곡 번호가 비워지고 `is_playing`이 `false`가 된다. 예약 목록 전체를 지우는 기능과는 다르다.

## 곡 번호 입력 오류

곡 번호 입력칸이 비었거나 숫자가 아니거나 음수이면 예약·우선예약·예약취소 요청을 보내지 않는다. 화면에 `곡 번호를 올바르게 입력하세요.`라는 안내가 표시된다. 현재 프론트엔드는 0을 입력하면 API까지 전달할 수 있으므로 실제 곡 번호에는 1 이상의 양의 정수를 사용한다.

## 자주 묻는 질문

### 예약한 곡은 어디서 확인하나요?

기기 중앙 화면의 `[예약]` 영역에서 쉼표로 구분된 곡 번호를 확인한다. 예약이 없으면 `(비어있음)`으로 표시된다.

### 예약한 곡을 바로 틀려면 어떻게 하나요?

곡 번호 입력칸을 비운 상태에서 `시작`을 누르거나 `예약된 곡 시작`이라고 요청한다. 목록 첫 곡이 재생 대상으로 선택된다.

### 취소 버튼을 누르면 예약이 모두 사라지나요?

아니다. 빨간색 취소 버튼은 현재 재생을 정지하는 명령이다. 특정 예약을 지우려면 곡 번호를 입력하고 `예약취소`를 사용한다.
