# 음성 명령과 AI Agent 사용 안내

이 문서는 텍스트·음성 입력이 노래방 상태 변경으로 이어지는 과정과 사용자가 확인할 사항을 설명한다.

## 텍스트 명령 사용

기기 중앙 아래의 자연어 명령창에 요청을 입력하고 `전송` 버튼을 누른다. Enter 키로도 전송할 수 있다. 프론트엔드는 현재 기기 상태와 명령을 `/api/v1/commands`로 보내고 백엔드는 Qwen3 1.7B를 통해 변경된 상태를 구조화된 형식으로 받는다.

명령은 한 문장으로 자연스럽게 입력할 수 있지만 현재 상태 모델에 정의된 기능만 실행한다. 음정·템포·음량·MR·자막·곡 재생·예약·취소·정지가 대표적인 허용 기능이다.

## 음성 명령 녹음

마이크 버튼 `🎙️`을 누르면 브라우저가 마이크 사용 권한을 요청한다. 말을 마친 뒤 정지 버튼 `⏹`을 누르면 녹음 파일을 서버의 `/api/v1/stt`로 전송한다. faster-whisper가 한국어 음성을 텍스트로 변환하고 인식된 문장이 비어 있지 않으면 기기 제어 명령으로 다시 전송한다.

음성 녹음 형식은 브라우저의 `audio/webm`을 기준으로 한다. 입력 파일은 서버에서 임시 파일로 처리하고 작업 후 삭제한다. 한 번에 15MB를 넘는 음성 파일은 거부한다.

## 구조화 출력과 검증

LLM은 자유로운 설명문 대신 `KaraokeMachine` 상태 구조에 맞는 결과를 반환한다. Pydantic은 음정·템포·볼륨 범위와 자막·리버브 허용값을 검증한다. 기존 상태와 결과가 같으면 `changed=false`가 반환되고 화면은 상태를 바꾸지 않는다.

Pydantic은 사용자의 의도를 이해하는 도구가 아니다. LLM이 반환한 데이터의 타입·허용값·범위를 확인하는 역할을 한다. LangChain은 `ChatOllama` 호출과 구조화 출력 연결에 사용된다.

## 지원하지 않는 요청

기기 상태 모델에 없는 기능이나 허용 범위를 벗어난 요청은 적용하지 않는다. 예시는 다음과 같다.

- 조명을 켜거나 끄는 기능
- 결제 또는 코인 구매
- 날씨·뉴스 검색
- 실제 음원을 내려받는 기능
- 100을 넘는 음량 설정
- 지원 목록에 없는 자막 언어

이러한 요청은 기기 상태를 유지하며 `명령이 모호/불가/범위초과로 판단되어 변경하지 않았습니다.`라는 이유가 표시될 수 있다.

## RAG 사용 도우미와 기기 제어의 차이

기기 제어 입력창은 상태를 변경하는 명령에 사용한다. 오른쪽 RAG 사용 도우미는 프로젝트 문서에서 사용법과 오류 해결 방법을 검색해 답하는 정보 안내 기능이다. RAG 질문은 기기 상태를 변경하지 않는다.

예를 들어 `키 올려줘`는 기기 제어 입력창에 넣고 `키는 어디까지 올릴 수 있어?`는 RAG 사용 도우미에 질문한다.

## 자주 묻는 질문

### 음성 인식 결과가 바로 실행되나요?

인식된 텍스트가 비어 있지 않으면 기기 제어 API로 전달된다. 이후 구조화 출력과 Pydantic 검증을 거쳐 상태가 반영된다.

### LLM이 모르는 기능도 실행할 수 있나요?

아니다. 현재 상태 스키마와 프롬프트에 정의되지 않은 기능은 상태를 변경하지 않는 것이 원칙이다.

### RAG에 질문하면 볼륨이 바뀌나요?

아니다. RAG는 문서 검색과 답변 전용이며 현재 기기 상태를 입력받거나 수정하지 않는다.
