# RAG 검색 자료 열람 기능

## 사용자 요구

RAG가 검색하는 원문 문서를 사용자가 화면에서 확인할 수 있게 한다. 기존 기기 제어 기능은 변경하지 않는다. 이 문서는 추가 구현 요구사항이며 구현 완료를 의미하지 않는다.

## 화면

- 기기 바깥 오른쪽 RAG 패널에 `검색 자료 보기` 버튼을 둔다.
- 버튼을 누르면 문서 목록과 원문을 보여주는 별도 대화상자를 연다.
- 목록에는 문서 제목, 파일명, 짧은 설명을 표시한다.
- 문서 선택 시 일부 발췌가 아니라 전체 원문을 스크롤해 읽을 수 있다.
- 자료가 프로젝트 자체 작성 안내이며 제조사 공식 설명서가 아님을 표시한다.
- RAG 답변의 각 출처에도 `원문 보기` 버튼을 두어 해당 문서를 바로 연다.
- 모바일에서도 열람 가능하며 닫기 버튼, Escape 닫기, 포커스 복귀를 지원한다.

## 백엔드 계약

- GET /api/v1/rag/documents: 실제 검색 대상 Markdown 문서 목록을 반환한다.
- GET /api/v1/rag/documents/{document_id}: 문서 전체 내용을 반환한다.
- 문서 ID는 서버에서 생성한 허용 목록으로만 실제 파일에 매핑한다. 요청 값을 파일 경로로 직접 결합하지 않는다.
- 알 수 없는 ID, 경로 이탈 시도는 404 등으로 거부한다.
- 문서 조회는 Ollama 및 벡터 인덱스가 준비되지 않았어도 가능해야 한다.
- 검색 범위와 열람 목록이 같도록 공통 문서 목록 함수를 사용한다.
- 인덱스가 아직 갱신되지 않았다면 현재 원문과 검색 인덱스 버전 차이를 숨기지 않는다.

## 렌더링 및 검증

- 원문과 제목은 textContent로 표시하여 문서의 HTML/스크립트를 실행하지 않는다.
- 목록, 전체 원문, 출처에서 바로 열기, 빈 목록, 파일 없음, 모델 서버 없이 조회, 경로 이탈 차단을 테스트한다.
- 기존 기기 제어 API 및 상태에는 쓰기 작업을 하지 않는다.
